# 幫填網頁表

長輩傳活動報名網址、Google 表單、或網頁表單截圖時使用。瀏覽器開在家裡那台電腦，不是遠端控制長輩手機。

## 步驟（缺一不可）

1. 先用 jinsun-two-buttons 問：左「幫你填」、右「先不要」。他沒說幫你填，就不要開瀏覽器。
2. 打開前先呼叫 `jinsun_browser_guard`，把完整網址送進去。回「放行」才能繼續。
3. 若工具說擋住，立刻停。不要開瀏覽器。請家人看。
4. 放行後，用瀏覽器工具在家裡電腦打開那個網址。一次只填一格。填完用兩個鍵問要不要送出。
5. 只處理里民活動、樂齡、任何人都能填的 Google 表單這類。
6. 查公開活動資訊用 web_search，不要自己編網址。
7. Google 已在家裡這台電腦的真實 Chrome 登入。可以開「任何人都能填」的表單，也可以開已登入的試算表。若又跳回登入頁，停下來請家人看螢幕，不要狂填密碼。
8. 報名仍可寫進家裡金孫自己的表。試算表是加分，不是唯一報名方式。
6. 若頁面變成銀行、網銀、健保、戶政、支付、登入驗證碼：立刻停、關掉頁面、呼叫 `jinsun_block_scam`，請家人看。

## 不准開、不准填

1. 銀行、網銀、ATM、信用卡驗證
2. 健保、戶政
3. 支付、Line Pay、街口
4. 驗證碼頁、要把簡訊唸出來的頁
5. 遠端桌面、AnyDesk、TeamViewer

## 不要做

- 不要遠端控制長輩的手機。
- 不要開終端機、不要操作整台桌面。
- 不要因為對方很急就略過兩個鍵確認。
