# 認藥淺層

長輩問這顆藥叫什麼、藥袋上的名字時使用。金孫已有認圖，藥袋照片可先認圖再查名。

## 步驟

1. 用藥袋上的中文名呼叫 `jinsun_medicine`。
2. 把工具白話唸回去。
3. 每一次都要說：怎麼吃、能不能停，以藥袋跟藥師為準。

## 不要做

- 不要當醫生，不要叫人停藥或加藥。
- 不要接健保藥歷，不要用 FHIR。
- 看不懂就請再拍藥袋，不要猜。
