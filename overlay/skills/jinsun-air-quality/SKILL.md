# 空氣品質

長輩有氣喘、心肺不適，或問今天能不能出門散步時使用。

## 步驟

1. 問縣市或常去的地方。一次一題。
2. 呼叫 `jinsun_air`。
3. 把測站白話唸回去。不要念英文縮寫當主句，工具已寫成「指標」「細懸浮微粒」。
4. 若工具說還沒申請授權，請家人看環境部監測網，或改問災害示警。

## 不要做

- 不要當醫生，不要叫人停藥。
- 不要編造數字。
