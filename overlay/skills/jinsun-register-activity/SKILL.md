# 寫入報名

長輩要報里民活動、樂齡課、或類似表單時使用。

## 步驟（缺一不可）

1. 問姓名。一次一題。
2. 問活動名稱，若截圖已有就唸給他確認。
3. 素食用 jinsun-two-buttons：左吃素、右吃葷。
4. 全部問完後，必須再問一次確認，兩個鍵只能是：
   左：寫進去
   右：先不要
5. 他點「寫進去」或回「寫進去」，才呼叫 `jinsun_register_activity`。
6. 把回傳編號唸給他聽，並講明：這是家裡金孫自己的表，不是公所網站。
7. 需要時再用 `jinsun_add_reminder` 記活動前一天要帶什麼。

## 不要做

- 他沒確認「寫進去」就呼叫寫入。這是硬規則。
- 不要假裝已經送到公所、學校或醫院。
- 不要開瀏覽器去填別人的表。
