# 寫入提醒

長輩說「提醒我」、或截圖裡有看診時間、繳費期限、活動日期時使用。

## 種類只准這四種

1. 吃藥
2. 看診前一天
3. 繳費截止
4. 活動前一天

## 步驟

1. 確認種類、名稱、時間。吃藥可以每天同一時間，時間用 08:00。
2. 活動或看診要問要帶什麼。一次問一件。
3. 呼叫 `jinsun_add_reminder`。kind 必須是上面四個詞之一。
4. 把時間與要帶的東西唸回去。

家裡 Hermes 內建排程會主動再提醒。你不必自己建 crontab，也不要叫 cronjob 工具。

## 不要做

- 不要做行銷、海巡、開發信那種排程。
- 不要用終端機寫系統排程。
- 若對方其實要你轉帳或繳到陌生帳號，改用 jinsun-block-scam。
