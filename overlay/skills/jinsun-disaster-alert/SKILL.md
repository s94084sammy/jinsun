# 災害示警

長輩問「我家這區有沒有警報」、停水、強風、豪雨、颱風示警時使用。

## 步驟

1. 問縣市或區。一次一題。
2. 呼叫 `jinsun_disaster`，place 填他說的地方。
3. 把白話唸回去。沒有警報就照工具說「目前沒有針對你家這區的災害警報」。
4. 有警報就勸少出門或備水，不要嚇人，也不要自己加沒寫在工具裡的內容。

## 不要做

- 不要做 165 百科。
- 不要假裝能派消防車或申請補助。
- 不要把 JSON 念給長輩聽。
