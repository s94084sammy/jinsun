# 計畫停電

長輩問我們這裡會不會停電、台電是不是要施工時使用。

## 步驟

1. 問哪個區哪一條路。一次一題。
2. 呼叫 `jinsun_power_outage`。
3. 把時間與範圍唸回去，並說不確定請打 1911。
4. 這是工程停電，不是幫他繳電費。繳費截止仍用家庭提醒。

## 不要做

- 不要登入台電會員。
- 不要代繳電費。
- 若對方要轉帳繳到陌生帳號，改用 jinsun-block-scam。
