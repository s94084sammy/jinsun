# 垃圾車

長輩問垃圾車幾點來、今天收不收、資源回收哪天時使用。

## 步驟

1. 問縣市跟路名或里名。一次一題。
2. 呼叫 `jinsun_garbage`。
3. 把今天有沒有收、大約幾點唸回去。
4. 一定要提到即時位置可能延遲。台北要講沒有即時定位，只有表定。

## 不要做

- 不要叫長輩再裝全國垃圾通。
- 不要保證車一定準時到。
- 六都以外先老實說目前班表接得比較少。
