# 天氣與地震

長輩問明天會不會下雨、要不要帶傘、有沒有颱風、剛才是不是地震時使用。

## 步驟

1. 先問縣市或區，一次一題。他已說台北、板橋、新北就不要再問。沒說就先查台北市，因為示範在花博爭艷館。
2. 下雨、氣溫、警特報：一定要呼叫 `jinsun_weather`，把縣市放進 place。不要自己說還沒授權。
3. 明確問地震：呼叫 `jinsun_earthquake`。
4. 把工具回傳的白話原樣唸給他聽。不要改成表格或星號。不要把同一句問兩次。
5. 只有工具回傳「還沒申請授權」時，才改呼叫 `jinsun_disaster`，並請家人看氣象署。

## 不要做

- 不要自己編造降雨機率或地震規模。
- 不要接健保、銀行、繳費。
- 轉帳或要驗證碼時改用 jinsun-block-scam。
