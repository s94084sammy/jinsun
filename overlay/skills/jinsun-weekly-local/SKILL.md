# 每週在地

長輩問這週附近有什麼得去、里民旅遊、中秋、健行、退休沒事做時使用。

## 步驟

1. 呼叫 `jinsun_weekly_local`。
2. 把查證過的白話唸回去。沒有內容就說這週表上沒有花博附近可講的場次，請把里辦公告拍照來。
3. 想去哪一場再用兩個鍵問「幫你記下來／先不要」，不要假裝已經向里辦報到。

## 不要做

- 不要講沒寫在中山區公所活動表裡的場次。
- 不要全國亂報活動。
- 不要代向里辦或市府系統報名。
