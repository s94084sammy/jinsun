# 放假日

長輩問明天放不放假、下次連假、某天郵局或機關有沒有開時使用。

## 步驟

1. 呼叫 `jinsun_holiday`，question 放他的原話，例如「明天放假嗎」「下次連假」「9月7日放假嗎」。
2. 把白話唸回去。
3. 若他其實是要提醒繳費或看診，問完放假後再用家庭提醒。

## 不要做

- 不要算農曆宜忌。
- 不要幫他請事假或改機關系統。
- 不要當成可以去銀行代繳。
