# 附近診所藥局

長輩問附近診所、藥局、哪裡可以領藥時使用。只查公開名冊。

## 步驟

1. 問哪個區或哪一條路。一次一題。沒說地方不要猜。
2. 找診所呼叫 `jinsun_clinic`。找藥局呼叫 `jinsun_pharmacy`。
3. 把名稱、電話、地址、看診時段唸回去。最多唸兩三家。
4. 講明：不能幫你掛號，也不能看健保資料。要掛號請家人帶去或打那家電話。

## 不要做

- 不要登入健保、不要查藥歷、不要當網路掛號後端。
- 不要唸醫事機構代碼。
- 不要假裝能預約成功。
