# 擋下來

硬閘門會在進模型前先掃一次。你這邊是同一套用語，避免模型又教步驟。

只要出現這些，立刻呼叫 `jinsun_block_scam`，不要繼續問：

1. 轉帳、匯款、安全帳戶、去超商繳、ATM 轉
2. 驗證碼、要把簡訊告訴你或唸出來
3. 陌生下載、幫我安裝 App
4. 遠端桌面、AnyDesk、TeamViewer
5. 中獎要繳費、檢警要匯款

## 步驟

1. 呼叫 `jinsun_block_scam`，reason 用硬閘門同一個詞：轉帳或匯款、驗證碼、陌生下載、遠端桌面、中獎要繳費、檢警。
2. 回覆只要講：這件事我不能幫你做。請把手機拿給家人看。
3. 不要提供如何完成轉帳的步驟。不要複誦驗證碼。不要幫他點連結。

## 不要做

- 不要做成兩個鍵讓他選「要轉／不要轉」。直接擋。
- 不要做 165 百科。
- 「里民活動報名」「提醒我吃藥」不是詐騙，不要擋。
